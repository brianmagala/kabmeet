# Design System

- **Brand**: IndabaX Deep Green (`#065A4B`) primary navigation/surfaces, Signal Green (`#00E676`) primary actions (dark text), KAB Blue (`#0072BB`) links/Host badge, Sun Yellow (`#F5EC1E`) highlights/speaker ring (dark text), Amber Gold (`#F6A623`) accents, Live Red (`#E5484D`) LIVE badge/errors, Night Forest (`#0A1F1A`) Watch/Room background, Mist (`#F2F7F5`) light background.
- **Typography**: Oswald headings, Poppins body/navigation.
- **Icons**: `lucide-react` only, consistent stroke width, zero emoji in UI.
- **Shape**: Pill buttons, 12px card radius, 8px spacing grid.
