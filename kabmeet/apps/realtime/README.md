# @kabmeet/realtime

Socket.IO + Redis + Yjs realtime service for Kabmeet.

## Modules

- `src/chat` — Live chat, Top chat ranking, slow mode, pinned messages, stickers, and moderation
- `src/polls` — Live audience polls and Q&A upvoting
- `src/presence` — Live viewer counts, peak viewers, raised-hand queue, and speaker status
- `src/workspace` — Yjs CRDT document sync for shared notes, tasks, and collaborative code
