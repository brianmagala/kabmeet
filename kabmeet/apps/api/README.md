# @kabmeet/api

NestJS REST API and domain backend for Kabmeet.

## Modules

- `auth` — Authentication, session cookies, and server-side role guards
- `users` — Profiles, role assignments, and notifications
- `communities` — IndabaX, KAB AI, and student club spaces
- `sessions` — Live streams, scheduled sessions, and replays
- `classes` — Private virtual classes restricted to enrolled students
- `attendance` — Automatic join/duration tracking and CSV export
- `video` — LiveKit room token issuance and speaker promotion
- `admin` — Platform-wide moderation, roles, and reports
